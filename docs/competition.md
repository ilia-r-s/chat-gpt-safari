# Safari Chat and AlliHat

Comparison checked November 20, 2026 against Safari Chat 0.3.9 and AlliHat’s Mac App Store listing and product guides. The Safari Chat evidence comes from the implementation and browser tests. The AlliHat evidence comes from its publisher. No hands-on AlliHat session was performed. [AlliHat on the Mac App Store](https://apps.apple.com/us/app/allihat/id6760651569) · [Safari Chat feature coverage](parity.md) · [Browser verification](validation.md)

## What AlliHat can do that Safari Chat currently lacks

| User task | AlliHat | Safari Chat |
| --- | --- | --- |
| Ask about a scanned PDF or an image | Sends PDF documents to supported cloud providers so the model can use the pages and layout. The ChatGPT connection also supports image questions. Apple’s on-device option excludes PDF attachments. [PDF guide](https://allihat.com/summarize-pdf-safari) · [App Store description](https://apps.apple.com/us/app/allihat/id6760651569) | The attachment reader accepts UTF-8 text, code and tabular data. It cannot supply the original PDF or image to the model. [Attachment reader](../extension/panel/attachments.js) |
| Save the current article to Notion or turn it into a Todoist task | Offers a connected-app directory and accepts compatible remote MCP servers. Connected apps are available in regular chat. [Connected-app guide](https://allihat.com/integrations) | The sidebar has browser actions and hosted web search. Our MCP integration runs in the opposite direction. A desktop client can invoke Safari tools. The sidebar cannot import a remote app’s tools. [Desktop integration](../plugins/safari-chat/README.md) · [Tool catalog](../extension/core/agent.js) |
| Choose a different AI provider or keep inference on the Mac | Supports Claude, Gemini, Grok, Perplexity, OpenRouter, compatible custom endpoints and Apple’s on-device model. The Apple route requires compatible hardware and macOS 26 or later. Tools vary by provider. [Provider setup](https://allihat.com/help) · [Custom endpoints and model limits](https://apps.apple.com/us/app/allihat/id6760651569) | Both Chat and Work call OpenAI. The user can choose a ChatGPT plan connection or an OpenAI API key. Neither route runs inference locally. [Request implementation](../extension/core/agent.js) |
| Reuse a workflow or a preference across unrelated chats | Offers one-click saved workflows and editable, individually removable chat memories. [Workflow examples](https://allihat.com/) · [Chat Memories release notes](https://allihat.com/updates) | Local history, drafts and retry branches preserve an individual conversation. There is no saved-prompt library or cross-chat memory feature. [Conversation features](parity.md) |
| Find an old conversation from a phrase in its answer | Searches message bodies and displays a matching excerpt. All Chats can also start a conversation independently of a webpage. [History and standalone chat release notes](https://allihat.com/updates) | Recents filters the titles of locally saved conversations. The regular user entry point opens chat in a website tab. [History filter](../extension/panel/panel.js) · [Dock behavior](parity.md) |
| Summarize a captioned YouTube video or a nested Reddit thread | Opens YouTube’s transcript panel when needed and retries delayed transcripts. Its Reddit reader expands collapsed discussions and reports partial coverage. [YouTube guide](https://allihat.com/summarize-youtube-safari) · [Reddit reader release notes](https://allihat.com/updates) | Page sharing can include cues from a displayed caption track. The general browser tools can interact with a page, but the extension has no dedicated YouTube transcript or Reddit thread reader. [Page capture](../extension/content/page.js) |

## Where Safari Chat offers a documented difference

| User task | Safari Chat | What AlliHat documents |
| --- | --- | --- |
| Click or type while staying in ordinary Chat | A Chat turn can use the same approved browser tools as Work. The user can look up a quote, edit a field or draw without changing modes. [Agent](../extension/core/agent.js) · [Cross-tab workflows](../tests/tab-workflows.mjs) | Its guide explicitly requires enabling Agent Mode for browser clicks and typing. Its connected-app actions have a separate rule and work in ordinary chat. [AlliHat’s explanation](https://allihat.com/capacities-safari-extension) |
| Keep an OpenAI API key in the macOS Keychain | The native companion saves provider credentials in an app-specific Keychain vault shared with the Safari extension. Users can keep separately named key connections and histories. [Credential store](../native/Shared/CredentialStore.swift) · [Account model](architecture.md) | The publisher specifies Safari local storage for AI provider keys and the Mac Keychain for connected-app credentials. These are distinct types of credentials. [Published storage policy](https://apps.apple.com/us/app/allihat/id6760651569) |
| Continue using a personally built extension without a separate extension subscription | This source build has no extension subscription check. OpenAI plan eligibility or API billing still applies. Live shared credentials require a properly signed Mac build. [Build and connection instructions](../README.md) | The publisher requires an AlliHat subscription after the seven-day trial, including when using an existing ChatGPT plan or Apple’s on-device model. Its published US price is $29.99 per year. [Pricing and billing](https://allihat.com/help) |

## Safari Chat workflows worth comparing hands-on

These workflows have concrete Safari Chat implementations. The reviewed AlliHat materials describe general page automation but do not establish equivalent behavior or a product limitation. [AlliHat’s Agent Mode description](https://allihat.com/chatgpt-safari-extension)

| Workflow | Safari Chat evidence | What remains unknown about AlliHat |
| --- | --- | --- |
| Draw one timed stroke in another tab | A test opens a background canvas, checks that it is hidden, draws after automatic activation, and verifies ink, elapsed time, one press and one release. The original chat returns after the task. [Paint workflow](../tests/tab-workflows.mjs) | Whether a user can specify timing and paths, and whether an agent can select and return from another tab unaided. |
| Scroll until a carousel comes into view and swipe the pictures both ways | WebKit checks the selected slides, the stopping position, a variable-speed pointer path and a single continuous turtle stroke. Additional checks cover simultaneous contacts, pen pressure and wheel units. [Carousel workflow](../tests/carousel-workflow.mjs) · [Gesture tests](../tests/gestures.mjs) | Which physical gesture equivalents, speed controls, stopping conditions and cancellation behavior are exposed. |
| Refresh during an approval or streamed reply | The original task, its pending approval, draft and buffered answer reconnect in the source tab. WebKit checks that approval and model requests are not replayed. [Navigation workflow](../tests/webkit-dock.mjs) | AlliHat documents preserving the conversation on sidebar-link navigation and deferring such a link until a reply finishes. That describes a different interaction from a user refreshing the source page mid-approval. [App Store release history](https://apps.apple.com/us/app/allihat/id6760651569) |
| Set a deadline and an action allowance for each message | Both limits are user-adjustable. The panel shows the remaining actions and retains a specific failure reason. [Settings](../extension/core/config.js) · [Run tests](../tests/background.test.js) | AlliHat describes a progress-sensitive budget for Agent Mode. Its release notes do not specify a user-settable wall-clock deadline, a numerical action allowance or a comparable remaining-action display. [Budget change](https://allihat.com/updates) |
| Let a desktop MCP client request a Safari action | The local stdio server advertises ten tools and checks that the client can ask for approval. Discovery and refusal are tested. Signed end-to-end desktop handoff remains a live installation check. [Native server](../native/App/DesktopMCP.swift) · [Protocol smoke test](../tests/mcp-smoke.mjs) | AlliHat documents acting as a client of remote MCP servers. Its published guide does not establish that it can also serve a desktop client over stdio. [MCP setup](https://allihat.com/integrations) |
