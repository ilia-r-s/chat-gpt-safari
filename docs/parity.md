# Chrome extension comparison

The reference for this build is OpenAI’s published Chrome side-chat illustration and browser extension guide, inspected November 18, 2026. It shows a compact header, a right-aligned question, an inline work summary, message actions and a bottom composer with an approval control. OpenAI lists Chrome, Edge, Brave, Opera and Vivaldi. Safari Chat implements its own macOS extension using public interfaces. [Official guide and illustration](https://learn.chatgpt.com/docs/chrome-extension) · [Official Chrome listing](https://chromewebstore.google.com/detail/chatgpt/hehggadaopoacecdllhhajmbjkdcmajg)

| Feature | Safari Chat 0.2.0 |
| --- | --- |
| Side chat | The dock reserves space on the right and adjusts common fixed page controls. Drag or use the keyboard to resize. The header opens recent chats, starts a chat, opens it in a tab, shows settings and closes the dock. The product keeps its own name. |
| Conversation and composer | Right-aligned user messages, plain assistant replies, copy/edit/retry actions, light/dark/system appearance and a rounded bottom composer. A completed tool-assisted reply shows measured elapsed time. The permission control explains Safari’s approval policy. |
| Page and selection | Right-click **Ask Safari Chat** to attach the selection or the page. The attachment appears in the composer for review before sending. Toolbar opening and automatic dock restoration read no page text. |
| Tab mentions | Type `@`, filter by tab title or address, then choose with the keyboard or pointer. Use **+ → Add browser tabs** for multiple tabs. Listing accessible tabs reads metadata. Choosing a tab reads its bounded excerpt. |
| Navigation | While its background session is active, Safari Chat reopens an explicitly docked chat on an accessible page in the same tab and restores the local conversation. Navigation can interrupt a running reply. A standalone chat tab stays open through page navigation. Safari controls website access, and complex layouts may work better in that separate tab. |
| Files and captions | Up to six sources total. File selection, drop and paste support UTF-8 text, code and data up to 200 KB per file. Distinct same-name files keep their identities and formatting. Sharing a page can include timestamped captions already exposed by a visible video’s displayed text track. Availability on YouTube depends on its player and the page. PDF, image, audio/video uploads and hosted file management are outside this build. |
| Accounts and models | Browser-hosted ChatGPT OAuth, eligible plan usage or separately named API-key connections. The native app owns selection, refresh, explicit key replacement and sign-out. Settings shows available models and supported reasoning efforts. Production account and plan access require live verification. |
| History | Account-separated local history, drafts, recent-chat search and Markdown export. Edit/retry creates a new branch. Concurrent edits preserve separate copies. The public integration does not expose existing ChatGPT cloud chats, projects, library files or memories. |
| Browser actions | Ten approved operations cover reading the viewport, tab listing, clicking, filling fields, selecting options, changing checkboxes/radio buttons, scrolling, navigation and opening/closing tabs. The panel shows the concrete pending action. Support includes accessible carousels and scroll regions. OS dialogs, closed shadow roots, cross-origin frames and arbitrary canvas/drag manipulation remain outside the executor. |
| Search and citations | Opt-in hosted web search through the public Responses API with streamed progress and clickable local citations. Availability depends on model and account. Safari page access has separate approval. |
| Desktop | An experimental local MCP plugin offers the Safari tools to compatible desktop threads. Approvals return to the originating request. Signed Safari-to-ChatGPT routing still requires live verification. Built-in desktop tab mentions and control from regular cloud conversations require integrations outside this package. |
| Setup and cleanup | A native Mac app contains the Safari extension, account manager and cleanup controls. Browser and native cleanup verify their own storage scopes. User exports, backups and OS records have separate lifetimes. Signing and provisioning are required for live credentials. |
| Other platforms and hosted features | This preview targets macOS. Voice, image generation, downloads and iOS/iPadOS are outside its current scope. |

The browser and native fixture checks cover the interactions described in the validation record. Hosted behavior and signing depend on the installed environment and account.
