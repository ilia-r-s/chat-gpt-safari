Open Safari Chat

    

    
  1. Open Safari Chat.app from Finder and connect your account there.
  2. In Safari → Settings → Extensions, enable the extension included with that app.

    
If you added a temporary extension, it can preview the interface but cannot connect to the companion app. This development build needs to be run from SafariChat.xcodeproj in Xcode with signing configured for both targets.

Browser permissions
You choose which pages to share and approve each browser change. Safari manages website access. A separate chat tab stays open during navigation.

    
Requires the Safari Chat desktop plugin and the signed app. Requests from the plugin show their approvals in ChatGPT. This does not connect Safari to ChatGPT's built-in browser integration.

    
Context & efficiency
Smaller context uses fewer tokens. Older turns and long pages may be trimmed.
