Open Safari Chat

    

    
  1. Open Safari Chat.app from Finder and connect your account there.
  2. In Safari → Settings → Extensions, enable the extension included with that app.

    
If you added a temporary extension, it can preview the interface but cannot connect to the companion app. This development build needs to be run from SafariChat.xcodeproj in Xcode with signing configured for both targets.
