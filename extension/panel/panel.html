Open Safari Chat

    

    
  1. Open Safari Chat.app from Finder and connect your account there.
  2. In Safari → Settings → Extensions, enable the extension included with that app.

    
Using a development build?
A temporary extension previews the interface. To connect an account, run the Safari Chat scheme from SafariChat.xcodeproj with both targets signed, then enable its extension in Safari.

    

  
  
    
Settings

    
    
    

    

      Website access
      
      
Rules match the exact hostname for this account and Safari profile. Blocked sites take priority. Safari manages its own website permissions.

      

        
        

      

      
    
    
    
    
    ChatGPT desktop control
      
      
    The local Safari Chat plugin sends approvals to the originating ChatGPT thread. Requires the signed companion app.
    
    
    
    
    Context and usage
      
    Local context
    
      
    Page size limits each excerpt. The input budget covers excerpts and messages together. Recent turns includes your current message.
    
      
      
      
    
    
    
    
    
    Remove your data
      
    Erase this profile’s chats, drafts and settings, plus all Safari Chat accounts saved on this Mac. Active tasks stop. Run cleanup in each profile before uninstalling.
